# Звёздный атлас

Официальный сайт приложения для изучения всех 88 созвездий на iPhone и iPad.

Статический сайт публикуется GitHub Pages из ветки `main`, корень репозитория.
Страницы поддержки и конфиденциальности включены. Реклама, формы регистрации, аналитика и сторонние шрифты отсутствуют.
